# gta6-guia

Web estática (GitHub Pages) con guía de GTA VI en español: checklist con progreso guardado en el navegador, datos clave y FAQ.

## Cómo se mantiene
- Todo el contenido vive en `data.js`. `index.html` no se toca salvo para mejoras de diseño.
- Los `id` de la checklist no se cambian nunca: el progreso de cada visitante se guarda por id.
- Solo datos confirmados por Rockstar o por al menos dos fuentes fiables. Nada de rumores ni texto copiado de otras webs.
- Cada actualización se anota en `CHANGELOG.md` con fecha y fuentes.
- Prohibido: trucos/mods de pago, venta de cuentas o dinero del juego, material con copyright de Rockstar (logos, capturas ajenas).
